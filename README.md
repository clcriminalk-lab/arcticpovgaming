# Arctic POV Gaming

A responsive, no-build gaming discovery landing page. Arctic POV Gaming helps players find their next game through a curated catalogue, genre filters, search, and a lightweight save-to-library interaction.

The catalogue includes **Football Auction Night**, a standalone football squad auction game. Open `football-auction-night.html` directly or choose **Play now** from the catalogue.

## Run locally

Open `index.html` in a browser. The site uses plain HTML, CSS, and JavaScript. Google Fonts load over the network; system sans-serif fallbacks keep the layout readable offline.

## Publish with GitHub Pages

This repository is configured to publish from `main` at the repository root. GitHub Pages builds the site automatically after each commit.
